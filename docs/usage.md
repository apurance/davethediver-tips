# 使用说明

[返回 README](../README.md)

在线使用：[davethediver-tips.pages.dev](https://davethediver-tips.pages.dev/)

## 内容与功能

- 35 条攻略：推进、潜水、武器饰品、菜谱、员工分店、养殖农场、重点 Boss、活动、图鉴小游戏、DLC。
- 本地数据库：470 条食谱、131 条独立食材、285 条鱼类和 33 条员工记录（2026-10-21 快照）。中英文搜索、排序、分页、菜谱用途 / 鱼类区域 / 员工评级筛选；详情保留来源链接和缺失值。
- 食谱 → 食材 → 来源鱼类，以及食材 / 鱼类 → 食谱的双向跳转；配队建议可打开员工详情。
- 7 道代表菜谱的已核对等级曲线、经营建议和备货计算；与数据库共用名称和关联条目。
- 省操作 / 手动补芥末两套人员搭配。
- 两店分别取整的备菜需求、加成与成本估算、日产瓶颈、升级机会成本回本计算器。
- 全文搜索（Ctrl+K）、阶段筛选、Boss 剧透开关、收藏、日常清单与打印。
- 收藏、清单和偏好保存于浏览器 localStorage，不发送给服务器；计算参数仅保留本次会话。
- 桌面侧栏、移动目录抽屉与响应式卡片。表格在手机上可横向滚动。
- React Router 路由：`/recipes` 食谱、`/ingredients` 食材、`/fish` 鱼类、`/staff` 员工。详情地址如 `/recipes/tiger-shark-sushi`、`/ingredients/tiger-shark-meat`、`/fish/tiger-shark`、`/staff/billy` 可直接打开、刷新和分享。详情链接使用当前条目的正式 ID。
- `/search?q=关键词` 同时检索数据库和攻略，阶段筛选仅影响攻略；`/bookmarks` 为攻略收藏。`/tools?recipe=tropical` 保留原有备货链接，旧 `/#recipes` 链接自动跳转。
- `/maps` SVG 地图：蓝洞深海 A / B 两份方格地形各有 01–03 三套分布；冰河＋热泉（450–570 米）共用 C 地形，也有 01–03 三套分布。可按区域筛选物资、矿石和鱼类，切换方格线和鱼名、放大地图，并下载含图例的独立 SVG。网址如 `/maps?type=B&layout=03` 或 `/maps?type=C&layout=02` 可直接打开并在刷新后保留选择。

## 本地保存与联网

收藏、清单和偏好保存在当前浏览器的 `localStorage`，不上传服务器，也不会跨浏览器、设备或域名同步。清除站点数据会删除这些记录。计算器参数仅保留本次会话。

页面不调用实时外部 API，也不加载外部字体或图像。通过本地开发服务加载应用后可断网阅读；在线站点的首次加载以及打开外部资料链接仍需要联网。
